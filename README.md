# MERIDIAN

An auditable, advisory-only trading research platform. MERIDIAN watches **Gold, Silver, Crude Oil, Bitcoin, Ethereum and XRP**, runs research through specialized workers, applies deterministic risk controls, and issues committee memos to the human CIO, who alone decides and executes trades elsewhere. It then monitors positions the CIO records and advises **HOLD / EXIT / REVIEW**.

> **MERIDIAN contains no order-execution code.** The only outbound market client is GET-only and restricted to Coinbase's public `/market/*` endpoints; a test fails the build if order-related code appears.

## Your risk rules (defaults, editable in Risk Command with password re-entry)

* Starting capital **$700** (`STARTING_CAPITAL`).
* **Max loss per trade = 10% of equity ($70).** Size = floor(budget ÷ (|entry − stop| × contract size)). If one contract would risk more than $70, the idea is **BLOCKED**.
* **Total open risk across all positions ≤ 10%.** Recording a position automatically sends other open recommendations back through risk, so you cannot accidentally stack two $70 risks.
* Capital usage up to 100% of equity (your instruction). Futures margin is not in Coinbase's public API, so enter it per asset (`margin_per_contract`) or ideas stay **RESTRICT: MARGIN_UNVERIFIED**.
* Leverage ceiling: gross notional ≤ 10× equity. Daily loss limit 10%, weekly 20%. Event blackout 60 min before / 30 min after high-impact USD events (plus crude/OPEC events for oil).

## Quick start

```bash
cp .env.example .env            # set JWT_SECRET, CIO_USERNAME, CIO_PASSWORD
docker compose up --build       # http://localhost:8000
```
Log in, go to **Executive Overview → Run end-to-end pipeline on simulated data**, open the memo in **Research Laboratory**, record a CIO decision.

Without Docker, see [docs/LOCAL_DEVELOPMENT.md](docs/LOCAL_DEVELOPMENT.md). For Railway, see [docs/DEPLOYMENT_RAILWAY.md](docs/DEPLOYMENT_RAILWAY.md).
